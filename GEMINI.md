# User Directives & Permanent Rules

- **STRICT PROHIBITION ON GIT PUSH**: NEVER run `git push` or push code to any remote repository under any circumstances without explicit, advance permission and consent from the user.
- **ALWAYS COMMIT LOCALLY WHEN DONE**: Always create a clean git commit locally with a clear, descriptive commit message whenever a task, feature, or bugfix is completed. Never push to remote.
- **STRICT PROHIBITION ON DUMMY / SIMULATED / UNREAL WORK OR DATA**: NEVER create, insert, simulate, fabricate, or hardcode any dummy, mock, fake, placeholder, or simulated users, leads, messages, tasks, or data anywhere in the codebase, database, or UI under any circumstances. Absolutely NO simulations or unreal work. Only genuine, authentic data and real user interactions are permitted.
